# Vibe Island

> macOS Notch status panel — a Dynamic Island experience for Claude Code, Codex, and Gemini CLI

[![Download](https://img.shields.io/badge/Download-Latest-blue?style=for-the-badge&logo=apple)](https://dl.vibeisland.app/VibeIsland.dmg)
[![macOS](https://img.shields.io/badge/macOS-14.0+-black?style=flat-square&logo=apple)](https://github.com/edwluo/vibe-island-updates/releases)
[![Sparkle](https://img.shields.io/badge/Updates-Sparkle-orange?style=flat-square)](https://sparkle-project.org/)

## Features

- **Real-time status** — see Claude Code / Codex / Gemini CLI status in your Notch area
- **Permission approval** — approve or deny permission requests directly from the panel
- **Interactive Q&A** — answer AskUserQuestion prompts by clicking options in the GUI
- **Precise terminal jump** — click a notification to jump to the exact terminal window/tab/pane
- **Auto updates** — built-in Sparkle for seamless version updates

## Install

1. **Download** — click the blue button above to download the DMG
2. **Install** — open the DMG, drag Vibe Island to Applications
3. **Launch** — first launch auto-configures hooks for Claude Code, Codex, and Gemini CLI

## Supported Terminals

iTerm2 · Ghostty · Terminal.app · Warp · VS Code · Cursor · Alacritty · Kitty · Hyper · Zed
