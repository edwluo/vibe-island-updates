## What is Vibe Island?

Vibe Island shows live status for Claude Code, Codex, Gemini CLI, Cursor, and 20+ other AI coding agents in the MacBook notch — permission approvals, question prompts, precise jump-back to the exact terminal that asked, and per-provider usage limits. Learn more at [vibeisland.app](https://vibeisland.app), or head to the [community repo](https://github.com/vibeislandapp/vibe-island) for bug reports and feature requests.

## Release notes

Every Vibe Island update ships here as a GitHub release and reaches the app automatically via Sparkle. The complete version history is also on the [changelog](https://vibeisland.app/changelog/).

## Install

1. Download the DMG and drag Vibe Island to Applications
2. Launch — detected AI coding CLIs are configured automatically, no setup needed
3. Future updates arrive in-app; no manual downloads
